Mozi's — Inhalte bearbeiten

Kein Programmieren nötig · exportiert content.json

So funktioniert's

  1. Felder unten ausfüllen oder ändern (Preise, Texte, Karten, FAQ, ...).
  2. Unten auf „Datei herunterladen" klicken — du bekommst eine Datei namens content.json.
  3. Diese Datei auf GitHub in deinen Repo-Ordner hochladen und die alte content.json damit ersetzen (auf GitHub: Datei anklicken → Stift-Symbol „Edit" oder „Upload file" → die neue Datei auswählen → „Commit changes").
  4. Die Website lädt die neuen Inhalte automatisch beim nächsten Aufruf — kein weiterer Schritt nötig.
